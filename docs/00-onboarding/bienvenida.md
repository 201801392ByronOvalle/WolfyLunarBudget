# Introducción

¡Bienvenido!

Wolfy Lunar Budget es un proyecto personal desarrollado con el objetivo de construir una aplicación moderna para la administración del presupuesto personal, reemplazando una hoja de cálculo tradicional por una solución web completa.

Además de ser una herramienta de uso diario, este proyecto sirve como laboratorio de aprendizaje para reforzar conocimientos de arquitectura de software, desarrollo Full Stack y buenas prácticas de programación.

Si eres un nuevo desarrollador o un asistente de inteligencia artificial, este documento será tu punto de partida.

---

# Flujo de Trabajo Recomendado

Cada nueva funcionalidad debería seguir el siguiente proceso:

1. Revisar el Roadmap.
2. Comprender la arquitectura relacionada.
3. Diseñar la solución.
4. Implementar.
5. Validar el funcionamiento.
6. Actualizar la documentación si es necesario.
7. Actualizar el Roadmap.

---

# Principios Fundamentales

Toda contribución al proyecto debe respetar los siguientes principios:

- Simplicidad.
- Código limpio.
- Arquitectura modular.
- Reutilización.
- Escalabilidad.
- Consistencia.
- Documentación actualizada.

---

# Qué Debe Evitarse

No modificar la arquitectura sin una razón justificada.

No duplicar componentes.

No introducir nuevas dependencias innecesarias.

No generar código difícil de mantener.

No dejar documentación desactualizada.

No romper las convenciones establecidas.

---

# Filosofía del Equipo

El objetivo no es desarrollar funcionalidades lo más rápido posible.

El objetivo es construir un software:

- Fácil de entender.
- Fácil de mantener.
- Fácil de extender.

Cada cambio debe dejar el proyecto en un mejor estado del que fue encontrado.
