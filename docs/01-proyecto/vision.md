# Visión del Proyecto

## Wolfy Lunar Budget

---

## Descripción

Wolfy Lunar Budget es una aplicación web privada orientada a la administración del presupuesto personal.

El proyecto nace con el objetivo de reemplazar una hoja de cálculo de Microsoft Excel utilizada para controlar ingresos, gastos, ahorros y metas financieras, proporcionando una solución moderna, centralizada y accesible desde cualquier dispositivo.

Además de resolver una necesidad personal, el proyecto funciona como una plataforma de práctica para reforzar conocimientos de desarrollo Full Stack, arquitectura de software y buenas prácticas de programación.

---

# Objetivos

Los objetivos principales del proyecto son:

- Centralizar toda la información financiera personal.
- Registrar ingresos, gastos y movimientos de ahorro.
- Organizar el dinero mediante cuentas independientes.
- Clasificar movimientos utilizando categorías.
- Llevar el seguimiento de metas financieras.
- Administrar presupuestos mensuales.
- Visualizar indicadores financieros mediante un dashboard.
- Mantener la información sincronizada en una base de datos en la nube.

---

# Alcance Inicial (MVP)

La primera versión del sistema contempla las siguientes funcionalidades:

- Dashboard financiero.
- Administración de movimientos.
- Administración de cuentas.
- Administración de categorías.
- Administración de metas.
- Administración de presupuestos mensuales.
- API REST para acceso a la información.
- Persistencia de datos mediante PostgreSQL.

No forman parte del MVP:

- Multiusuario.
- Compartir presupuestos.
- Integraciones bancarias.
- Aplicación móvil.
- Notificaciones.
- Exportación avanzada de reportes.

---

# Público Objetivo

Inicialmente el sistema está diseñado para un único usuario: el propietario del proyecto.

La arquitectura, sin embargo, busca mantener suficiente desacoplamiento para permitir una futura evolución hacia un sistema multiusuario.

---

# Filosofía del Proyecto

Wolfy Lunar Budget busca priorizar:

- Simplicidad.
- Código limpio.
- Arquitectura modular.
- Componentes reutilizables.
- Escalabilidad.
- Buenas prácticas de desarrollo.
- Aprendizaje continuo.

El proyecto debe servir tanto como herramienta personal como portafolio profesional.

---

# Principios de Desarrollo

Durante el desarrollo del proyecto se procurará mantener los siguientes principios:

- Favorecer la claridad sobre la complejidad.
- Evitar duplicación de código.
- Mantener responsabilidades bien definidas.
- Documentar las decisiones importantes.
- Implementar funcionalidades de forma incremental.
- Priorizar mantenibilidad antes que optimizaciones prematuras.
